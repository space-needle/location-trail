# iOS Location Tracker App

This repository contains the source code for a simple iOS Location Tracker application. The code was generated by an AI assistant and provides the foundation for an app that can:
- Track a user's location (latitude and longitude).
- Store the location data locally on the device using Core Data.
- Display the recorded locations for a specific day on an Apple Map.
- Allow the user to configure tracking settings.

Since the code was generated in an environment without Xcode, you need to follow these instructions to build and run the application.

## How to Build the Project

### Prerequisites
*   A Mac with the latest version of Xcode installed. You can download it from the Mac App Store.

### 1. Create a New Xcode Project
1.  Open Xcode and select **Create a new Xcode project**.
2.  In the template chooser, select the **iOS** platform and then choose the **App** template. Click **Next**.
3.  Fill in the project options:
    *   **Product Name**: `LocationTracker`
    *   **Team**: (Select your Apple Developer account if you have one)
    *   **Organization Identifier**: A reverse-domain name, like `com.yourname`.
    *   **Interface**: `SwiftUI`
    *   **Language**: `Swift`
    *   **Storage**: Select **None**. We will add Core Data manually based on the files provided.
4.  Click **Next** and choose a location on your Mac to save the project.

### 2. Add the Generated Files to Your Project
1.  Locate the `LocationTracker/LocationTracker` directory containing all the Swift source files.
2.  In Xcode, open the Project Navigator (the folder icon on the left).
3.  Drag all the Swift files (`LocationManager.swift`, `DataController.swift`, `ContentView.swift`, `ConfigView.swift`, and `LocationTrackerApp.swift`) from the Finder into the Project Navigator, right under your project's main folder.
4.  A dialog box will appear. Make sure **"Copy items if needed"** is checked and that your app `LocationTracker` is added to the target. Click **Finish**.
5.  Xcode will likely have created its own `ContentView.swift` and `LocationTrackerApp.swift`. It is safe to replace these with the files you are dragging in.

### 3. Configure `Info.plist` for Location Permissions
Your app needs to declare why it's using the user's location.
1.  In the Xcode Project Navigator, find and open the `Info.plist` file.
2.  Click the `+` button next to any existing key to add a new one.
3.  Add the following two entries. You can search for their names or type them in full:
    *   **Key**: `Privacy - Location When In Use Usage Description`
    *   **Type**: `String`
    *   **Value**: `We need your location to show you on the map and track your movements.`
    *   **Key**: `Privacy - Location Always and When In Use Usage Description`
    *   **Type**: `String`
    *   **Value**: `This app tracks your location in the background to record your movements throughout the day.`

### 4. Create the Core Data Model
1.  In the Xcode Project Navigator, right-click the `LocationTracker` group, and select **New File...**.
2.  Scroll down to the **Core Data** section and select **Data Model**. Click **Next**.
3.  Name the file `LocationTracker.xcdatamodeld` and click **Create**.
4.  Click on the new `LocationTracker.xcdatamodeld` file to open the visual editor.
5.  Click the **Add Entity** button at the bottom and name the new entity `Location`.
6.  With the `Location` entity selected, go to the **Attributes** section and click the `+` button to add three attributes:
    *   `latitude`: set the type to `Double`.
    *   `longitude`: set the type to `Double`.
    *   `timestamp`: set the type to `Date`.
7.  In the right-hand sidebar (the Data Model Inspector), ensure the `Location` entity is selected. Under the "Class" section, change the **Codegen** option to **Class Definition**. This is a critical step that makes your entity compatible with the provided `DataController.swift` code.

### 5. Enable Background Location Updates
To allow the app to track location when it's not on screen:
1.  Click on the `LocationTracker` project at the top of the Project Navigator to open the project settings.
2.  Select the **Signing & Capabilities** tab.
3.  Click **+ Capability**.
4.  Search for and add **Background Modes**.
5.  In the newly added Background Modes section, check the box for **Location updates**.

### 6. Build and Run
You are all set! You should now be able to build and run your project.
*   Select an iOS Simulator or a connected physical iPhone from the scheme menu at the top of the Xcode window.
*   Click the **Run** button (the triangular play icon).

The app will launch, and upon enabling tracking, it will ask for location permissions. For the best results, especially with background tracking, testing on a physical device is recommended.
